# 新深圳集群 sz-k8s-prod：队列调度使用说明

本文档只介绍深圳集群和云网不一样的地方。页面步骤、表单校验、排队和位次见 [`gpu-queue-scheduling.md`](gpu-queue-scheduling.md)。开发容器的 Helm 和 Deployment 见 [`sz-k8s-prod-pod.md`](sz-k8s-prod-pod.md)。

> **日期**：2026-10-26。工作台上的已用卡数会变，以页面刷新后的数字为准。

| 项 | 值 |
|---|---|
| 集群 | 任务页下拉选 `sz-k8s-prod` |
| 现在能提交 | H200 训练。队列 `q-h200-train`，上限 16 张 |
| 队列机器 | `sz-h200-9`、`sz-h200-10`，每台 8 张。一个副本最多 8 张 |
| 数据盘 | 打开 Scratch，挂到 `/scratch`。没有共享盘 |
| 出网 | H200 训练任务自动带上 HTTP 代理 |
| 镜像仓库 | `https://harbor.sz-prod.hqzyai.com:8443/` |
| 批量推理 | 还没有开放 |
| H800 | 工作台上可能有数字，现在不能选来提交 |

## 先记住这几条

- 集群选 `sz-k8s-prod`，GPU 型号选 H200，任务类型选训练。
- 打开「启用 scratch」，来源选「新建」。数据集和 checkpoint 写到 `/scratch`。副本数保持 1。
- Workspace 保持「不挂载工作目录」，也不要追加 PVC。
- 一个副本不要超过 8 张卡。蓝条里的「配额上限」按命名空间计算，可能比这 16 张更小。
- 现在不要选 H800，也不要选批量推理。这次不做多机训练。
- 工作台提交的 H200 训练任务会自动带上公网代理。自己创建的开发容器不会自动带上。

## 1. 存储

深圳队列没有云网那种 `h3c-csi-sc-nfs` 或 `h3c-csi-sc-epc` 共享盘，Workspace 下拉是空的。

打开「启用 scratch」，来源选「新建」：

| 字段 | 值 |
|---|---|
| 容量 | 正整数 Gi，不超过页面写出的集群上限 |
| 挂载路径 | 固定 `/scratch` |
| 存储类 | `local-path`。盘在调度到的那台机器的 `/data` 上 |

这块盘只在一台机器上。任务第一次调度到哪台，文件就留在哪台。换机器后要继续用这些文件，用「复用已有」选原来的 scratch。两份任务同时挂同一块盘时，后提交的会一直等待。

副本数大于 1 时，scratch 开关是灰的。深圳队列把副本数保持为 1，一张机器最多 8 张卡。

不打开 scratch 时，文件只能写在容器可写层。详情页「临时盘 / 副本」就是这块的上限，表单里不能改。2026-10-26 一张 1 卡任务显示的是 48Gi。任务删除后，写在 `/`、`/tmp` 和镜像目录里的文件会消失。

## 2. 网络

工作台提交的 H200 训练任务，容器里已经有这些变量，不用在表单里再填：

| 变量 | 值 |
|---|---|
| `http_proxy`、`https_proxy`、`HTTP_PROXY`、`HTTPS_PROXY` | `http://33.1.42.5:8888` |
| `no_proxy`、`NO_PROXY` | `localhost,127.0.0.1,::1,10.244.0.0/16,10.96.0.0/12,.svc,.cluster.local,cluster.local,.hqzyai.com` |

代理地址是 HTTP，不要改成 `https://33.1.42.5:8888`。`.hqzyai.com` 不要走代理，前面的点要保留。云网的队列任务没有这组变量。

自己用 Helm 创建的 H200 开发容器不会自动带上，写法见 [`sz-k8s-prod-h200-network.md`](sz-k8s-prod-h200-network.md)。

## 3. 镜像

镜像放在 `https://harbor.sz-prod.hqzyai.com:8443/` 的个人项目里。`sz-h200-9` 和 `sz-h200-10` 上已经有下面两张，地址整行照抄即可：

- `harbor.xa.hqzyai.com:19443/xuw/pytorch:v1.5`
- `harbor.xa.hqzyai.com:19443/llm-course/lab:v2`

其它大镜像不要从 `harbor.xa.hqzyai.com:19443` 现场拉。

## 4. 常见问题

### 为什么 Workspace 是空的，还必须开 scratch？

深圳队列没有可多机同时挂载的共享盘。数据盘只有 Scratch。不打开时，训练写出的文件落在容器可写层里，2026-10-26 的 1 卡任务这块只有 48Gi，任务删除后就没了。

### 队列上限是 16 张，为什么蓝条只允许更少的卡？

16 张是 `q-h200-train` 的队列上限，分在两台机器上。蓝条「配额上限」是你这个命名空间的总配额。2026-10-26 有的命名空间 GPU 总配额上限是 4 张。合计卡数超过总配额，向导会提示「超过命名空间配额上限」。若「卡型额度」里还有一行已生效的 H200 上限，以更小的那个为准，规则见 [`gpu-queue-scheduling.md`](gpu-queue-scheduling.md)。一个副本仍然不要超过 8 张。

### 为什么选了 H800 提交不了？

H800 正在调整机柜，现在调度不到。工作台上那一格的数字不要当成可以提交的卡。卡型选 H200。

### 为什么工作台任务能访问公网，自己建的 Pod 会超时？

工作台提交的 H200 训练任务已经带上 `http://33.1.42.5:8888`。自己创建的 H200 容器不会自动带上，见 [`sz-k8s-prod-h200-network.md`](sz-k8s-prod-h200-network.md)。

### 为什么不能做多机训练，也不能提交批量推理？

各台 GPU 机器之间没有共享盘，这次也不提供多机训练。批量推理还没有开放。当前只提交 H200 训练，副本数为 1。

### 换了一台机器之后，scratch 里的文件还在不在？

还在第一次调度到的那台机器上。新任务若调度到别的机器，挂不上这块盘，会一直等待。要继续用这些文件，用「复用已有」选原来的 scratch。确认不再需要之后，再删除这块 PVC。
